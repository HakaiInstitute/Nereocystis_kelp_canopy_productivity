# Changelog
All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [v1.3.0] - 2026-08-04
### Updates
- added new compiled file nereo_sbulb_combined.csv, pooling all Sbulb_max measurements from nereo_metrics.csv and nereo_size.csv into one long-form table, with a data_source column (nereo_metricsT1/T2/T3 or nereo_size)
- added new script sbulb_combined.R to generate nereo_sbulb_combined.csv
- updated Data_dictionary.csv and README.txt to document nereo_sbulb_combined.csv and sbulb_combined.R


## [v1.3.0] 
- 2026-07-30
### Updates
- added new data file that pertains to blade turn over, nereo_blade_turnover.csv
- added summer 2026 data to:
- nereo_size.csv
- nereo_density.csv 
- nereo_harvest.csv 
- nereo_metrics.csv 
- added variables (Bcount1, Sbulb_max1, Sbulb_max3)
- changed variable Sbulb_max to Sbulb_max2
- removed variables Dbulb and Sbulb10 (not relevant and very little data)
- metrics_long.csv 
- metrics_rates.csv
- added Sbulb_growth rate parameter and Sbulb_growth rate_interval (and data dictionary)  
- nomenclature changes in metrics_rates.csv and R script, reflected in data.dictionary
- added variable for change in Sbulb_max over time

- 2026-01-19
### Added

- nereo_size.csv

- nereo_harvest.csv

### Change
- Changed the data package title to: Nereocystis kelp canopy productivity data from BC Central Coast, v1.3.0
- renamed harvest.csv to nereo_harvest.csv
- renamed tag_additional.csv to nereo_tag_additional.csv
- renamed metrics.csv to nereo_metrics.csv and removed data where only sub-bulb diameter information was collected 
- created nereo_size.csv for instances where additional sub-bulb-diameters were measured across the population 
- combined density.csv and binned_density.csv into one spreadsheet : nereo_density.csv  
- updated README document to match changes
- updated Data_dictionary document to match changes
- changes “line” variable to “transect” to match other datasets
